# ESP32-C3 内置 ADC 单通道采集 + 上位机 (adc_app)

基于 **ESP32-C3 最小系统板内置 ADC（ADC1）** 的单通道信号采集固件，配合 **Python 上位机** 实时显示波形并完成滤波。

采集信号（如 ECG / PCG / PVDF）→ ESP32-C3 定时采样 → 经 USB(COM) 串口发送 → 上位机滤波（10-600Hz 带通 + 50Hz 陷波）+ 实时绘图。

## 硬件连接

| 信号 | 通道 | GPIO |
| ---- | ---- | ---- |
| 模拟输入 | ADC1_CH1 | **GPIO1** |

> 输入信号需偏置到约 1.5V 中点，量程 0 ~ 3.1V（`ADC_ATTEN_DB_12`，12bit 原始值 0~4095）。
> 采样率默认 **2000 Hz**（`adc_app.h` 中 `ADC_SAMPLE_RATE_HZ` 可调，须同时在上位机 `--rate` 指定相同值）。

## 数据流

```
ADC(ESP32-C3 内部 ADC1) --esp_timer 定时采样--> 环形缓冲 --> main.c 逐批打印
  --> 控制台 vfs 双写(UART0 + USB Serial/JTAG) --> PC 串口 COM
  --> host/host_app.py 解析 D: 行 --> 50Hz 陷波 + 10-600Hz 带通 --> 实时绘图
```

固件通过控制台输出文本协议：

```
D:v1,v2,...,vN\n     一批原始 12bit 样本 (0~4095)，每行最多 200 个
I (...) xxx          其余行为 ESP-IDF 日志，上位机自动忽略
```

## 构建与烧录

```bash
idf.py set-target esp32c3
idf.py build
idf.py -p COM10 flash monitor
```

或直接运行项目根目录 `build.cmd` 完成构建。

## 上位机使用（GUI）

```bash
cd host
pip install -r requirements.txt
python host_app.py            # 界面内操作即可
```

启动后在界面中：

1. **选择串口**（如 COM10，点击 ⟳ 可刷新列表）与**波特率**（115200）
2. 点击 **「连接」**，状态灯变绿即开始实时采集
3. 波形区上方为**原始信号**（12bit，0~4095），下方为**滤波后信号**；底部为实时 **FFT 频谱**（可勾选开关）
4. **「滤波模式」** 一键切换：**ECG/PCG**（10-600Hz 带通）或 **PPG**（0.5-15Hz 带通）；可再勾选/取消 **「50Hz 陷波」「带通」**、调整 **陷波 Q** 观察滤波效果
5. **「自动跟踪工频」**：每隔 2s 从原始信号估计实际市电频率并自动对准陷波中心（界面右侧会显示 `工频跟踪 @ xx.xx Hz`）
6. **「录制 CSV」** 选择保存路径即可记录数据（列：index,raw,filtered,time_ms），**「清屏」** 重置显示与统计

> **纵轴为手动控制**（不自动缩放）：鼠标滚轮缩放、按住左键拖动平移；右键 → **View All** 一键复位到完整数据范围。

> 绘图使用 **pyqtgraph**（实时波形引擎，自动峰值降采样，任意窗口大小均流畅）。
> Qt 绑定优先 **PySide6**，也可改用 **PyQt5**（`requirements.txt` 中二选一）。

命令行参数（可选，界面内可再改）：

| 参数 | 默认 | 说明 |
| ---- | ---- | ---- |
| `--port` | COM10 | 界面中默认选中的串口 |
| `--rate` | 2000 | 采样率 Hz，**须与固件 `ADC_SAMPLE_RATE_HZ` 一致** |

界面内可调项：采样率（须与固件一致）、显示窗口（1~30s）、FFT 开关、滤波开关、陷波 Q、工频自动跟踪、录制 CSV。

### 滤波

上位机实时滤波链路（`host_app.py` 顶部 `FILTER_MODES` 可增改模式，界面一键切换）：

**滤波模式预设：**

| 模式 | 带通 | 适用信号 |
| ---- | ---- | ---- |
| ECG/PCG 心电/心音 | 10 ~ 600 Hz（4 阶） | 心电、心音 |
| PPG 脉搏 | 0.5 ~ 15 Hz（4 阶） | 光电容积脉搏波（主要能量 0.5~5Hz，保留重搏切迹） |

1. **50 Hz IIR 陷波**（`NOTCH_Q` 默认 20，界面可调）：抑制工频干扰
   - Q 越小陷波越宽，对市电频率漂移的容错越大（但会损伤邻近信号）
   - **自动跟踪工频**：市电实际频率可能在 49.9~50.1Hz 间漂移，固定 50Hz 陷波会漏陷；自动跟踪会锁定实际频率，实验表明可额外改善约 20dB
2. **Butterworth 带通**：范围取决于所选滤波模式

采用 `sosfilt` 状态保持方式逐批滤波，适合实时流式处理，无分段拼接误差。切换滤波参数/模式时按当前输入直流电平初始化滤波器状态，**不会出现大幅瞬态振荡**；自动跟踪工频的每次重调也有死区保护，不会频繁重建滤波器。

## 常见问题

* 上位机连不上串口：检查 `--port` 是否与设备管理器一致，ESP32 是否已上电。
* 无波形 / 数值恒定：检查信号是否接在 GPIO1，偏置电压是否在量程内。
* 时间轴不对：确认上位机 `--rate` 与固件 `ADC_SAMPLE_RATE_HZ` 一致。
* 改采样率后不生效：固件与上位机两处都要改，并重新编译烧录。

## 离线信号处理与回放工具

不需要硬件也能分析信号：读一个 CSV 文件，在界面上组合各种滤波方式，对比处理前后波形，并导出 WAV 直接听处理后的心音效果。

```bash
cd host
pip install -r requirements.txt   # 需要额外安装 PyWavelets
python offline_processor.py       # 打开界面操作，或
python offline_processor.py data.csv
```

界面说明：

1. **打开 CSV**：支持实时上位机「录制 CSV」的格式（`index,raw,filtered,time_ms`，自动选中 `raw` 列），也支持任意纯数值 CSV（自动选第一列）。右侧可切换**数据列**、设置**采样率**（默认 2000Hz，须与实际采集一致）。
2. **处理步骤**：添加/删除/上移/下移/清空一组顺序执行的滤波步骤，支持：
   - **脉冲去除**（碰撞噪声/大幅尖峰）：中值基线 + k·MAD 稳健检测，仅把被污染的连续段用线性插值替换，心音波形不损伤。参数：检测窗宽、阈值倍数 k、最大连续长度
   - **工频抑制**：从整段信号**实测市电频率**，对 f0/2f0/3f0（约 50/100/150Hz）**级联高 Q 零相位陷波**，工频及其谐波一起杀（状态栏显示实测频率）
   - **带通**（低截止 / 高截止 / 阶数）
   - **陷波**（中心频率 / Q，单点陷波）
   - **高通 / 低通**（截止频率 / 阶数）
   - **小波去噪**（小波基 db4/db8/sym4/sym8/coif2/haar，层数 0=自动，软/硬阈值）
   - **中值滤波**（窗宽）
3. **应用处理**：上下两个波形对比，上=处理前，下=处理后（均零相位滤波，`sosfiltfilt`）。纵轴为手动控制：滚轮缩放、拖动平移、右键 View All 复位。
4. **导出**：
   - **导出 WAV 试听**：把处理后信号写成 16bit 单声道 WAV（归一化到 0.9 峰值防削波），并自动用系统默认播放器打开，让你直接听心音是否清晰。
   - **导出 CSV**：数据写为 CSV（时间窗内）；**内容**选「两者对比」则 `index,time_s,original,processed` 两列，"处理后"仅 processed 列，"原始（滤波前）"仅 original 列。
   - **导出波形图**：Origin 风格 PNG —— **白底、蓝色曲线、黑色四边盒框、刻度朝内、浅色网格**（Arial 字体，Time(s)/Amplitude 轴标），可直接用于论文/报告。**内容**选「两者对比」时叠加灰色原始曲线（去直流）作对比，选「原始（滤波前）」导出原始波形。
   - **导出内容**：「两者对比 / 处理后 / 原始（滤波前）」三选一，同时作用于 CSV 与波形图。
   - **导出范围**：勾选「时间窗」用起止时间限定导出/出图区间；勾选「Y范围」用 Ymin~Ymax 限定波形图幅值窗口（不勾选自动）；**「同步视图」**一键把当前可见范围填入导出设置（「内容」为原始时同步上方原始波形，否则同步下方处理后波形）。

> 典型心音处理链：**脉冲去除 → 工频抑制 → 20-600Hz 带通 → 小波去噪**。
> 脉冲先去（避免大尖峰干扰工频测量），再用「工频抑制」一次清掉 50/100/150Hz，
> 带通限定频段，最后小波去噪压底噪（实测底噪可降约 28dB，心音保留 ~70%）。
> 实测工频漂到 50.06Hz 时仍能自动对准并抑制 20dB 以上。
